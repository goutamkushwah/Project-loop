Project Description:
LOOP is an AI-powered web application that collects customer feedback from multiple sources. It analyzes feedback using AI, performs sentiment analysis, groups similar feedback into themes, displays analytics dashboards, and allows users to ask questions using AI.

Main Features:
✓ Authentication
✓ Role-Based Access Control
✓ Feedback CRUD
✓ CSV Upload
✓ Search & Filter
✓ Analytics Dashboard
✓ AI Sentiment Analysis
✓ Theme Clustering
✓ Ask LOOP AI
✓ Voice of Customer Report
✓ Responsive Design
